# Стиль фронтенда — `base-nova`, библиотеку примитивов (Base UI) не меняем

При переходе на стоковый стиль shadcn выбран пресет `base-nova`: меняется только
визуальный стиль (`lyra` → `nova`, более плотные отступы под дашборд-разметку),
библиотека примитивов остаётся Base UI (`@base-ui/react`), а не Radix UI. `Nova`
в дефолтной конфигурации использует Lucide/Geist — это уже совпадает с текущим
`iconLibrary: "lucide"` проекта. Base UI поддерживает `Drawer.Root
swipeDirection="right"` нативно, так что открытие Drawer справа не требует смены
библиотеки.

Переход на `radix-nova` был бы дополнительной, гораздо более рискованной сменой
рантайм-библиотеки почти во всех `components/ui/*` (другое API компонентов,
использование `vaul` вместо Base UI для Drawer) — несмотря на то, что связка
Radix более распространена в экосистеме shadcn. Решение отложить эту смену
принято explicitly, а не по умолчанию: если в будущем понадобится перейти на
Radix, это отдельная задача, а не побочный эффект стилизации.

## Considered Options

- `radix-nova` — стандартная для экосистемы связка (Radix UI + vaul); отклонено
  на данном этапе как несоразмерно рискованное для задачи «привести к базовому
  стилю» без функциональной необходимости.
